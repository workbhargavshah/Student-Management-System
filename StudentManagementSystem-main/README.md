# 🎓 Student Management System

A web-based Student Management System developed using ASP.NET Core MVC, C#, Entity Framework Core, and MySQL.

## 🚀 About the Project

The Student Management System is designed to simplify student record management. It provides an admin dashboard to view and manage student information efficiently.

## ✨ Features

- 📊 Professional Admin Dashboard
- 👨‍🎓 Student Directory
- ➕ Add New Students
- ✏️ Edit Student Details
- 🗑️ Delete Student Records
- 🏫 Department Management
- 📚 Semester Information
- 🗄️ MySQL Database Integration
- ✅ Form Validation
- 💻 User-Friendly Interface

## ⚙️ Installation and Setup

### Prerequisites

- .NET SDK
- Visual Studio Code
- MySQL Server
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/jinjalariddhi2006/StudentManagementSystem.git
```

### 2. Open the Project

```bash
cd StudentManagementSystem
```

### 3. Restore Dependencies

```bash
dotnet restore
```

### 4. Configure MySQL

Create the database in MySQL:

```sql
CREATE DATABASE studentmanagementdb;
```

Configure your database connection using your local settings. Do not upload your actual database password or other secrets to GitHub.

### 5. Run the Application

```bash
dotnet run
```

Open the local URL displayed in the terminal.
